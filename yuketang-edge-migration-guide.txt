雨课堂 Edge 扩展迁移指令（v1.2.9）

一、把安装包带到新电脑
1. 下载 yuketang-edge-extension.zip。
2. 用 U 盘、网盘或其他你信任的方式把 ZIP 复制到新电脑。
3. 在新电脑把 ZIP 解压到一个固定目录，例如：
   %USERPROFILE%\Documents\YuketangEdgeExtension
4. 打开解压后的目录，确认里面直接能看到 manifest.json、content.js 和 README.txt。
   Edge 要加载这个目录；不要选择 ZIP 文件，也不要选外层又套了一层同名目录的文件夹。

二、在新电脑的 Edge 安装
1. 打开 Edge，在地址栏输入 edge://extensions 并回车。
2. 打开页面上的“开发人员模式”。
3. 点击“加载解压缩的扩展”（Load unpacked）。
4. 选择上面包含 manifest.json 的 YuketangEdgeExtension 文件夹。
5. 在扩展卡片确认名称为“雨课堂视频自动切换（Edge）”、版本为 1.2.9，且开关已启用。

三、运行
1. 在新电脑的 Edge 里正常登录雨课堂；登录状态不会随扩展 ZIP 迁移。
2. 打开 https://buaa.yuketang.cn/ 下的课程视频页面。
3. 使用页面右下角面板的下拉框选择播放起始视频，再点击“开始”。
4. 如果所选视频不是当前页面视频，扩展会先切换目录项；页面标题确认切换后会自动尝试播放。运行按钮在切换期间保持“停止”；若 Edge 拒绝自动播放，面板会另显示“授权播放”按钮，点击它不会停止任务。雨课堂可能复用同一个播放器地址，扩展不会再单靠媒体地址是否变化判断视频切换。右下角面板会显示实际运行版本。
5. 播放结束后扩展会选择下一条未完成视频并自动尝试播放。是否能免去每条视频的授权点击，取决于 Edge 对雨课堂的媒体自动播放权限；可通过 Edge 的 AutoplayAllowlist 策略放行该站点。

注意事项
- 保持扩展解压目录的位置不变；Edge 从该目录加载扩展。
- 更新版本时，将新版 ZIP 解压覆盖到这个目录，然后到 edge://extensions 点击该扩展的“重新加载”，再刷新雨课堂页面。
- 扩展只匹配 buaa.yuketang.cn，并只处理标记为“视频”的目录项；不会点击或回答作业。当前暂停的视频会依据页面实时状态续播；本地旧缓存不会覆盖该状态。
- 如果“开发人员模式”或“加载解压缩的扩展”不可用，可能是新电脑的组织策略禁用了本地扩展加载。
