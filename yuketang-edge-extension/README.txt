Edge 安装与更新
1. 第一次安装：在 Edge 打开 edge://extensions，打开“开发人员模式”，点击“加载解压缩的扩展”，选择本文件夹（含 manifest.json）。
2. 已安装旧版：用新版文件替换原扩展文件夹，再在 edge://extensions 点击该扩展的“重新加载”。
3. 禁用 Tampermonkey 中之前安装的同名脚本，避免两份脚本同时运行。
4. 刷新已登录的雨课堂视频页。右下角面板会显示扩展版本；确认是 v1.2.9 后，在下拉框选择“播放起始视频”并点击“开始”。开始后主按钮显示“停止”，切换视频时保持运行状态。若 Edge 拒绝新视频自动播放，主按钮仍显示“停止”，另一个“授权播放”按钮会出现；点击它只授权当前视频，不会停止自动切换。平台可能复用同一个播放器地址，因此扩展以页面标题确认视频切换，不依赖媒体 URL 改变。

迁移到另一台电脑：复制 ZIP 到新电脑并解压到固定文件夹；在新电脑 Edge 的 edge://extensions 打开“开发人员模式”，点“加载解压缩的扩展”，选择直接包含 manifest.json 的解压目录。然后在新电脑的 Edge 手动登录雨课堂并打开课程视频页。扩展文件不包含雨课堂登录状态。

只点击左侧标为“视频”的目录项，不点击或回答作业题目。进入新视频后读取右上角“完成度”：100% 则跳过，未满 100% 或读数暂不可用时会自动尝试播放。是否能免去每条视频的授权点击，取决于 Edge 的媒体自动播放权限；被拦截时使用单独的“授权播放”按钮，运行状态仍保持开启。当前播放器的暂停/结束状态优先于本地缓存，以免旧缓存阻止当前暂停视频续播。页面显示的历史观看记录以平台数据为准。
诊断：打开雨课堂页按 Ctrl+Shift+J 查看 Console，搜索“雨课堂 Edge”。启动时应看到“content.js 已注入 v1.2.9”“初始化完成”“视频目录映射”和“播放起点”；切换后自动尝试播放。若出现 NotAllowedError，说明 Edge 的媒体自动播放权限仍在拦截；面板会保留“停止”运行状态并显示“授权播放”按钮。旧的缓存标题不会再决定下拉框选择，带有（一）和（二）的标题会区分处理。
